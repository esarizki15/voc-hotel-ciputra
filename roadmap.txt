# Aspect-Based Sentiment Analysis (ABSA) Hotel Reviews
## Powered by Ollama Qwen3:8B

Proyek ini adalah sistem **AI-driven analysis** untuk mengekstraksi aspek dan sentimen dari ulasan hotel secara otomatis menggunakan Qwen3:8B model melalui Ollama, dengan dashboard Streamlit interaktif untuk visualisasi insights.

## Overview

### Tujuan Proyek
Mengembangkan pipeline end-to-end untuk:
1. **Ekstraksi Aspek & Sentimen** dari ulasan hotel menggunakan LLM lokal (Qwen3:8B)
2. **Analisis Prioritas Bisnis** melalui aggregasi dan normalisasi data
3. **Evaluasi Akademis** dengan metrik Precision, Recall, dan F1-Score
4. **Visualisasi Dashboard** interaktif untuk eksekutif dan tim manajemen

### Tech Stack
- **LLM Engine**: Ollama + Qwen3:8B
- **Backend**: Python (Pandas, Scikit-learn)
- **Frontend**: Streamlit
- **Visualization**: Plotly, Streamlit Charts
- **Dataset**: IndoNLU (terma_term-extraction-airy / hoasa_absa-airy)

## Instalasi & Setup

### Prerequisites
- Python 3.8+
- Ollama installed & running
- Git

### Step 1: Clone Repository
```bash
git clone <repository-url>
cd absa-hotel-analysis
```

### Step 2: Setup Virtual Environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### Step 3: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 4: Start Ollama & Load Model
```bash
# Di terminal terpisah, jalankan Ollama daemon
ollama serve

# Di terminal lain, pastikan model qwen3:8b tersedia
ollama pull qwen3:8b
ollama run qwen3:8b
```

### Step 5: Prepare Dataset
Download `train_preprocess.csv` dari IndoNLU dan letakkan di folder `data/`.

```bash
mkdir -p data
# Copy file CSV ke data/train_preprocess.csv
```

### Step 6: Run Dashboard
```bash
streamlit run app.py
```

Dashboard akan terbuka di `http://localhost:8501`

## Penggunaan Dashboard

### Tab 1: Live Demo
1. Masukkan teks ulasan di input field
2. Klik tombol **"Analisis AI"**
3. Sistem akan menampilkan:
   - Aspek yang teridentifikasi
   - Sentimen per aspek
   - Confidence score

### Tab 2: Hotel Intelligence
Visualisasi analytics dari dataset batch:
- **Top Complaints & Strengths**: Identifikasi aspek paling sering dikritik/dipuji
- **Priority Improvement Matrix**: Urutan perbaikan berdasarkan impact & frequency
- **Sentiment Breakdown**: Distribusi sentimen per departemen/kategori
